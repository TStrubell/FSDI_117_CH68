## 🔐 Environment Variables
This project uses environment variables to securely manage email configuration for the SGnG Contact Page. Django’s `send_mail()` function requires sensitive values such as the sender email, recipient email, SMTP host, and authentication credentials. To protect this information, the project loads these values from a local `.env` file that is excluded from version control.

A `.env.template` file is included to demonstrate the required structure and variable names. Developers should copy this file to `.env` and replace the placeholder values with their real credentials. This approach ensures secure configuration while keeping sensitive information out of the repository.

## 📄 .env.template (included in project)

## ⚙️ SECURE EMAIL CONFIGURATION — settings.py

import os

### 📬 Email Configuration (Secure)

- DEFAULT_FROM_EMAIL = os.environ.get("DEFAULT_FROM_EMAIL")
- CONTACT_EMAIL = os.environ.get("CONTACT_EMAIL")

- EMAIL_BACKEND = "django.core.mail.backends.smtp.EmailBackend"
- EMAIL_HOST = os.environ.get("EMAIL_HOST", "smtp.gmail.com")
- EMAIL_PORT = int(os.environ.get("EMAIL_PORT", 587))
- EMAIL_USE_TLS = os.environ.get("EMAIL_USE_TLS", "True") == "True"

- EMAIL_HOST_USER = os.environ.get("EMAIL_HOST_USER")
- EMAIL_HOST_PASSWORD = os.environ.get("EMAIL_HOST_PASSWORD")
