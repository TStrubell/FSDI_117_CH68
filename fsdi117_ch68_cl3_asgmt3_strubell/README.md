## **⭐ ASSIGNMENT 3 (HIGHLIGHTED)
How to Receive Email from My Portfolio Webpage**

Assignment 3 demonstrates the **full end‑to‑end workflow** of receiving an email from the SGnG Contact Page. This includes:
- **Frontend UI** (Light Mode, Dark Mode, bilingual support)
- **Form validation**
- **Backend logic** using Django’s send_mail()
- **Successful message confirmation**
- **Email delivery to the SGnG inbox**
- **Documentation of the entire workflow**

This assignment integrates **internationalization (i18n)** and **localization (l10n)** to support both **English** and **Spanish**, ensuring consistent translation across the portfolio.
